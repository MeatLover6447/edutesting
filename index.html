      undertale save guide

      • save your progress to a file for undertale
      • progress shouldnt wipe on refresh, will wipe on restart
      • just dont have undertale open while this is open

      TO EXPORT

      save in undertale and CLOSE OUT OF THE TAB first

      1. visit the undertale save editor at the top or here

      2. click connect

      3. click export all saves

      4. save this somewhere like in your email

      TO IMPORT

      do NOT have undertale open when you do this

      1. visit the undertale save edtior at the top or here

      2. click import all saves and select the file from before

      3. open undertale again and everything should be there!

      cloudmoon guide

      • requires personal device (phone works)
      • requires a google account

      1. visit https://web.cloudmoonapp.com/ on NOT chromebook

      2. make an account with google

      3. once you are in your account, set/add a password

      4. now visit CloudMoonBypass on chromebook

      5. sign in with your google email and password you set

      playing undertale bosses

      • u need a bit of a brain for this
      • u need to have gotten at least 1 save point in undertale first for this to work

      1. visit undertale save editor

      2. click "Cick here for save file presets that you can import" or here

      3. using the built in presets at top left, pick which boss u wanna fight

      4. click load

      5. click "⭐SAVE" for undertale.ini and file0 and itll download the 2 files

      6. go back to the undertale save editor

      7. in save files, select undertale.ini, click import save file, and choose the undertale.ini you downloaded from floweys time machine

      8. click file0 and do the same

      9. thats it, reload the undertale tab.
